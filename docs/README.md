## Diagrams

Every diagram in [`diagrams/`](diagrams/) is a black-and-white Excalidraw drawing saved as `*.png`. Each PNG carries its Excalidraw scene inside the image file, so it is both the picture and the editable source. To edit one, drag the PNG into [excalidraw.com](https://excalidraw.com). Then export it again as PNG with **Embed scene** ticked.

These docs exist in both the `paycore` and `flagmesh` repos. When you change one copy, update the other.
